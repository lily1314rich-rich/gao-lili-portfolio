# GAO LILI · 高丽丽

AI 导演 / AI 漫剧创作师 / 商业视觉内容制作人个人作品集。

单页响应式网站，包含精选项目、小元绒 IP、商业广告与 AI 漫剧，共 17 条视频作品。

## 网站文件

- `index.html`：网页、样式、交互及全部 20 张封面图片。
- `media/`：17 条完整 MP4 视频，使用相对路径，点击封面或标题弹窗播放。

漫剧封面来自对应视频真实截图。网页适配桌面与手机。

## GitHub Pages

在仓库 Settings → Pages 中，选择从 `main` 分支的根目录 `/` 发布。

保留 `index.html` 与 `media/` 的相对位置。
